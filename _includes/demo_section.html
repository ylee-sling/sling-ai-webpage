What you are seeing: both arms follow the same plan: reach above the handle, grasp it, pull the drawer open. The token-by-token model must stop and wait while it decodes each action, so the arm moves in bursts. VPA issues a fresh trajectory chunk every 10–14 ms, so the arm runs continuously at up to 100 Hz and never hesitates. VPA latency values are drawn from the 10–14 ms range measured in the paper; the VLA timing is a representative illustration. This is a browser simulation, not a recording of physical hardware.
